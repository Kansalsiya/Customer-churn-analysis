# 📊 Customer Churn Analytics for Business Decision Support

A business analytics project that analyzes customer churn using the IBM Telco Customer Churn dataset. The primary focus is not just predicting churn but understanding **why customers leave**, extracting actionable business insights, and recommending data-driven retention strategies.

---

## 📌 Project Overview

Customer retention is significantly more cost-effective than acquiring new customers. This project explores customer behavior patterns, identifies the factors influencing churn, and demonstrates how machine learning can support business decision-making.

Instead of treating machine learning as the final goal, the notebook emphasizes:

- Business understanding
- Exploratory Data Analysis (EDA)
- Customer segmentation
- Churn pattern analysis
- Actionable recommendations
- Predictive modeling as a decision-support tool

---

## 🎯 Objectives

- Understand customer churn behavior.
- Identify the major drivers behind customer attrition.
- Perform data cleaning and preprocessing.
- Generate business-focused visual insights.
- Build predictive models to estimate churn probability.
- Compare model performance.
- Recommend practical customer retention strategies.

---

## 📂 Dataset

**Dataset:** IBM Telco Customer Churn Dataset

The notebook automatically loads the dataset, making it easy to run directly in Google Colab.

Dataset contains information such as:

- Customer demographics
- Contract type
- Internet services
- Payment methods
- Monthly charges
- Total charges
- Tenure
- Churn status

## 💡 Key Business Insights

The analysis helps answer questions such as:

- Which customers are most likely to churn?
- Which services contribute to higher churn?
- How does contract type influence retention?
- What role do tenure and monthly charges play?
- Which customer segments require proactive intervention?

---

## 📌 Business Recommendations

Based on the analysis, the project proposes strategies including:

- Early retention campaigns for new customers
- Incentives for month-to-month contract users
- Personalized offers for high-risk customers
- Improved customer support initiatives
- Loyalty and engagement programs
- Predictive monitoring of churn probability
